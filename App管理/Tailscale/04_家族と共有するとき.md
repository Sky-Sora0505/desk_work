## 10-4. 家族と写真を共有するときの設計（将来）

Immich 導入後に家族を招待する場合の ACL 案です。家族は写真（2283）だけに届き、ポータルや自作アプリには届きません。

```json
"groups": {
	"group:family": ["kazoku-a@example.com", "kazoku-b@example.com"],
},
"grants": [
	{ "src": ["autogroup:owner"], "dst": ["tag:server"], "ip": ["tcp:22", "…現在と同じ…"] },
	{ "src": ["group:family"], "dst": ["tag:server"], "ip": ["tcp:2283"] },
],
```

順番が重要です。**ACL を先に変えてから招待**します（逆だと、招待した瞬間に家族が全サービスに届く時間ができる）。Immich 側でも家族ごとにアカウントを分け、見せたい写真は共有アルバムにし、自動登録は無効のままにします。招待後は家族の端末から「写真は見えて、ポータルは見えない」ことを確かめます。
