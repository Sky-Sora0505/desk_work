# Tailscale のコマンド

よく使うコマンドと、macOS で `tailscale` コマンドが落ちる問題の対処です。

## 15-2. Tailscale

| コマンド | 意味 |
| --- | --- |
| `tailscale ip -4` | 自分の Tailscale IPv4（`100.x.y.z`） |
| `tailscale status` | tailnet の端末一覧と状態（`offline, last seen 14h ago` など） |
| `tailscale status --json` | 同じ内容を JSON で。tailnet 名などの取り出しに |
| `tailscale version` | バージョン（脆弱性情報と照らし合わせる） |
| `sudo tailscale up --advertise-tags=tag:server --accept-routes` | 接続設定。**書かないオプションは初期値に戻る**ので、変えるときは既存のフラグも全部書く |
| `tailscale serve --bg --https=<ポート> http://127.0.0.1:<ポート>` | tailnet 内だけに HTTPS で公開（ts.net の証明書）。`--bg` で再起動後も残る |
| `tailscale serve status` / `tailscale serve --https=<ポート> off` | serve の確認 / 停止 |
| `tailscale funnel` | **使わない**（インターネット公開） |

## 5-4. tailscale コマンドのラッパー

公式サイト版は「GUI アプリ本体が CLI を兼ねる」作りで、シンボリックリンク経由で呼ぶと `bundleIdentifier is unknown` で落ちます。そこで、本体をフルパスで呼ぶだけの小さなスクリプトを置いています。

```bash
sudo mkdir -p /usr/local/bin
sudo tee /usr/local/bin/tailscale > /dev/null << 'EOF'
#!/bin/sh
exec /Applications/Tailscale.app/Contents/MacOS/Tailscale "$@"
EOF
sudo chmod +x /usr/local/bin/tailscale
```

過去に試した `~/.zshrc` のエイリアスが残っている可能性があります（**要確認**）。`which tailscale` が `aliased to` を返すなら `sed -i '' '/alias tailscale=/d' ~/.zshrc` で消します。bash のスクリプトや `sudo` ではエイリアスが効かないので、ラッパーが必要です。迷ったらフルパス `/Applications/Tailscale.app/Contents/MacOS/Tailscale` を直接使えば確実です。
