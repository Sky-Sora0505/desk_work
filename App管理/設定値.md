# 設定値（伏せ字の一覧）

このフォルダは公開リポジトリに置くため、実際の値を次の伏せ字に置き換えています。実際の値は Mac mini で右の欄のコマンドを打つと分かります。自分用に控えるときは、git に入らない `tools/values.local` に書きます（`tools/README.md`）。

| 伏せ字 | 意味 |
| --- | --- |
| `100.x.y.z` | サーバーの Tailscale IP |
| `your-tailnet` | tailnet 名 |
| `your-mac` | Tailscale 上のデバイス名（MagicDNS は `your-mac.your-tailnet.ts.net`） |
| `youruser` | macOS のユーザー名（ホームは `/Users/youruser`） |
| `Your-Mac` | ターミナルに表示される Mac の名前 |

## 2-1. サーバー本体

| 項目 | 値 | 確認方法 |
| --- | --- | --- |
| Tailscale IP（IPv4） | `100.x.y.z` | `tailscale ip -4` |
| Tailscale デバイス名 | `your-mac` | 管理画面 → ネットワーク → 機械 |
| tailnet 名 | `your-tailnet` | 管理画面 → DNS の上部 |
| MagicDNS 名 | `your-mac.your-tailnet.ts.net` | `tailscale status` |
| Tailscale タグ | `tag:server` | 管理画面の機械一覧 |
| macOS ユーザー名 | `youruser`（管理者。日常用の通常ユーザーは未作成） | `whoami` |
| ホームフォルダ | `/Users/youruser` | `echo $HOME` |
| PUID / PGID | `501` / `20`（staff） | `id -u` / `id -g` |
| シェル | zsh（対話）、スクリプトは bash | `echo $SHELL` |
| Homebrew | `/opt/homebrew/bin/brew` | `which brew` |
| docker コマンド | `/Users/youruser/.docker/bin/docker`（Docker Desktop 付属） | `which docker` |
| tailscale コマンド | `/usr/local/bin/tailscale`（ラッパー）→ 実体 `/Applications/Tailscale.app/Contents/MacOS/Tailscale` | `cat /usr/local/bin/tailscale` |

## 2-3. SSH 鍵

| ファイル（`~/.ssh/`） | 用途 | 注意 |
| --- | --- | --- |
| `id_ed25519` / `.pub` | 既存（2025年10月作成）。GitHub 用 | **上書きしない**。`ssh-keygen` で Overwrite を聞かれたら `n` |
| `id_ed25519_server` / `.pub` | サーバー接続用（2026-09-26 作成、パスフレーズ付き） | 他の Mac や Windows から接続するときに使う |
| `authorized_keys` | `id_ed25519_server.pub` を登録 | 権限 600 |
| `config` | `Host skymac` の定義（5章） | 権限 600 |
