## 13-3. バス予約アプリ（研修で作成）

| 項目 | 内容 |
| --- | --- |
| アプリ | Spring MVC + MyBatis + JSP + PostgreSQL |
| AP サーバー | 公式 `tomcat` イメージ。`javax.servlet` なら Tomcat 9、`jakarta.servlet` なら Tomcat 10.1 |
| 公開 | `100.x.y.z:8090:8080`（DB は非公開）、パス `/bus-app/` |
| デプロイ | Eclipse で WAR を作り `webapps/` に置く |
| 変更が必要なところ | DB 接続先を `localhost` から `db`（コンテナ名）に |
| 初期データ | 既存のリセット SQL（delete → insert、会員 `tanaka002`、バス停2→3 の路線）を `initdb/` に置く |

導入するときは、型 C（nginx 配下 `/bus-app/`、ポートなし）に寄せると ACL を触らずに済みます。
