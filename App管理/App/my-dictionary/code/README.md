# My辞書 📖

スマホで使う、検索エンジン付きの自分専用辞書アプリです。
Mac mini（Docker + Tailscale）に置いて、iPhone のホーム画面から開いて使う想定で作っています。

- **Node.js 標準機能 + SQLite だけ**で動きます（npm install 不要・依存パッケージ 0）
- 画面はスマホ専用レイアウト（PCで開いても中央寄せで使えます）

---

## 機能

| 機能 | 内容 |
|---|---|
| 下部の検索バー | Safari と同じく画面の下。下へスクロールすると小さくなり、上へ戻すと元に戻る。キーボードが出てもキーボードのすぐ上に付いてくる |
| 検索エンジン | 入力するたびに即検索。**単語・読み・意味**のすべてが対象。ひらがな/カタカナ、全角/半角、大文字/小文字の違いは無視。スペース区切りで **AND 検索**（例：`鍵 署名`）。完全一致 → 前方一致 → 部分一致 → 意味の中、の順に並ぶ。1〜2文字の打ち間違いも「あいまい一致」で拾う。一致した部分は黄色でハイライト |
| 左上のメニュー（≡） | 辞書の切り替え・**新しい辞書を作る**・辞書の名前変更/削除、今の辞書への単語追加・CSVインポート/エクスポート・タグ（分野）の管理 |
| 複数の辞書 | 「基本情報辞書」「英単語」のように辞書を分けて持てる。単語・タグは辞書ごとに別々。最初は「基本情報辞書」が1つ用意されている |
| ＋ボタン | 検索バーの右。① 単語を1つ追加 ② CSVからインポート ③ CSVにエクスポート（どれも今開いている辞書が対象） |
| 並び順 | **50音（あ→わ）→ アルファベット（A→Z）→ その他（#）**。「読み」があれば読みで、なければ単語そのもので並ぶ。右端の索引（あかさたな…A〜Z）をなぞるとその行へジャンプ |
| タグ（分野） | ハードウェア・ソフトウェア・経営…のような**分野分け用**。色は Mac の Finder と同じ7色から選べる。タグは辞書ごとに作る。1つの単語に複数付けられる |
| タグで絞り込む | 画面上部の「タグで絞り込む」→ タグの一覧から選ぶ（検索もできる）。上部には**選んだタグだけ**が表示され、× で外せる。複数選ぶと「どれかが付いている単語」を表示。一覧の下の「新しいタグを作成」で作成、「編集」で名前・色の変更と削除 |
| 単語の詳細 | タップで下から表示。タグをタップするとその場で付く/外れる。「＋ 新しいタグ」でその場で作成もできる。編集・削除も |
| オフライン | 一度開いたあとは、サーバーにつながらなくても最後のデータを表示（HTTPS で開いたとき） |
| ダークモード | iPhone の設定に自動で合わせる |

## Mac mini へのセットアップ

### 1. ファイルを置く

このフォルダ（`dictionary-app`）を Mac mini の好きな場所にコピーします。

```bash
# 例
mkdir -p ~/server
mv ~/Downloads/dictionary-app ~/server/
cd ~/server/dictionary-app
```

### 2. Docker で起動

```bash
docker compose up -d --build
```

確認：

```bash
docker compose ps                     # STATUS が healthy になればOK
curl http://localhost:8080/api/health # {"ok":true}
```

Mac mini のブラウザで http://localhost:8080 を開くと画面が出ます。

### 3. Tailscale 経由で iPhone から開く

**おすすめ：`tailscale serve` で HTTPS にする**（ホーム画面アプリ化・オフライン表示が使えるようになります）

1. Tailscale の管理画面（login.tailscale.com）→ **DNS** で **MagicDNS** と **HTTPS Certificates** をオンにする
2. Mac mini で：

   ```bash
   tailscale serve --bg 8080
   tailscale serve status   # 表示された https://〜.ts.net が辞書のURL
   ```

3. iPhone（Tailscale アプリをオン）の Safari で `https://<Mac miniの名前>.<tailnet名>.ts.net` を開く
4. 共有ボタン →「**ホーム画面に追加**」→ アプリのように全画面で使えます

> `tailscale serve` は Tailscale につながっている自分の端末にだけ公開されます（インターネットには出ません）。
> インターネットに公開する `tailscale funnel` は使わないでください。

**簡易版：HTTP のまま開く**
`http://<Mac miniの名前>:8080`（または `http://100.x.x.x:8080`）でも使えます。ただし HTTP だとオフライン表示は動きません。

### 公開範囲を絞る（任意・おすすめ）

`tailscale serve` を使う場合、同じ家の Wi-Fi の他の端末から 8080 番に直接つながる必要はありません。
`docker-compose.yml` の ports を次のように変えると、Mac mini 自身（＝tailscale serve）からしか届かなくなります。

```yaml
    ports:
      - "127.0.0.1:8080:8080"
```

変更後は `docker compose up -d` で反映します。

### ポート番号を変えたいとき

8080 が他のアプリ（bus-reservation-app など）とぶつかる場合は、左側だけ変えます。

```yaml
    ports:
      - "127.0.0.1:8081:8080"   # Mac mini 側を 8081 に
```

`tailscale serve --bg 8081` も合わせて変えてください。

## 運用

| やりたいこと | コマンド |
|---|---|
| 止める | `docker compose down` |
| ログを見る | `docker compose logs -f` |
| コードを更新したあと反映 | `docker compose up -d --build` |
| Mac mini 再起動後 | Docker Desktop が起動すれば自動で立ち上がる（`restart: unless-stopped`）。Docker Desktop の設定で「ログイン時に起動」をオンにしておく |

### バックアップ

辞書データは、すべての辞書をまとめて `./data/dictionary.db` の **1ファイル**に保存しています。

- いちばん手軽：辞書ごとに、左上メニュー（または ＋）→「**CSVにエクスポート**」（Excel や Numbers でも開けます）
- まるごと：コンテナを止めてから `data` フォルダをコピー

```bash
docker compose stop
cp -r data ~/Backup/dictionary-$(date +%Y%m%d)
docker compose start
```

## CSVの書き方（インポート用フォーマット）

### 基本の形

```csv
単語,読み,意味,タグ
原子性,げんしせい,トランザクションは全部実行されるか、全く実行されないかのどちらか,データベース
DHCP,,IPアドレスなどを自動で貸し出す仕組み,ネットワーク;頻出
ロールバック,ろーるばっく,"更新前ログで処理前の状態に戻す
（2行目も書けます）",データベース
```

テンプレート：アプリ内の「CSVからインポート」→「CSVの書き方」→「テンプレートCSVをダウンロード」、または `public/samples/template.csv`

### ルール

| 項目 | ルール |
|---|---|
| 1行目 | 見出し行 `単語,読み,意味,タグ` を書く（列の順番は自由。見出しで判定します） |
| 単語 | **必須**。最大200文字 |
| 読み | 空でもOK。ひらがな・カタカナどちらでも可。**50音のどこに並ぶかはこの読みで決まる**ので、漢字の単語には入れるのがおすすめ。英字の略語（DHCP など）は空にすると A〜Z のところに並ぶ |
| 意味 | **必須**。最大10,000文字。改行もOK |
| タグ | 分野の名前。空でもOK。複数は **`;`（セミコロン）** で区切る（例：`ネットワーク;セキュリティ`）。取り込み先の辞書にまだ無い名前は**新しいタグとして自動で作成**され、色は順番に割り当て（あとで変更可） |
| 取り込み先 | **今開いている辞書**に入る。別の辞書に入れたいときは、先に左上のメニューで切り替える |
| `,` `"` 改行を含むとき | そのマスを `"` で囲む。中の `"` は `""` と2つ重ねる（例：`"彼は""はい""と言った"`） |
| 文字コード | **UTF-8**（BOMあり/なし）・**Shift_JIS**（Excel で「CSV」保存したもの）どちらも自動判別 |
| 区切り | カンマ。タブ区切り（TSV）も自動で判別 |
| 空行 | 無視される |

**見出しとして認識される名前**

| 列 | 使える見出し |
|---|---|
| 単語 | 単語・用語・見出し・見出し語・言葉・word・term |
| 読み | 読み・よみ・読み方・ふりがな・フリガナ・reading・yomi・kana |
| 意味 | 意味・説明・解説・定義・meaning・definition・description |
| タグ | タグ・分野・カテゴリ・カテゴリー・tags・tag・category |

見出し行が無い場合は、列の数で判断します：2列＝単語,意味／3列＝単語,読み,意味／4列＝単語,読み,意味,タグ

### 取り込むときの選択

ファイルを選ぶとプレビューが出て、取り込める件数・辞書との重複・エラー行（何行目か）を確認できます。
同じ辞書の中で「単語」と「読み」が両方同じものを**重複**とみなし、次から選べます。

- **スキップ**：辞書にあるものは取り込まない（初期設定）
- **上書き**：意味とタグを CSV の内容で置き換える
- **両方残す**：重複していても追加する

### Excel・Numbers で作るとき

- **Excel**：A列=単語、B列=読み、C列=意味、D列=タグ にして「CSV UTF-8（コンマ区切り）」または「CSV」で保存
- **Numbers（Mac/iPhone）**：書き出し →「CSV」
- iPhone の「ファイル」アプリ・iCloud Drive に置けば、アプリの「CSVファイルを選ぶ」から直接選べます

### 基本情報辞書の初期データ

`public/samples/fe_terms.csv` は「基本情報技術者試験 用語まとめ（グループ別・覚え方つき）」の用語 **304語** を、読み・意味（🧠覚え方・⚠️引っかけ入り）・分野タグ付きで CSV にしたものです。

- **初めて起動したとき（data フォルダが空のとき）、自動で「基本情報辞書」に入ります**
- 分野タグ：ネットワーク／セキュリティ／データベース／ハードウェア／ソフトウェア／クラウド／プロジェクトマネジメント／システム監査／経営
- 入れたくない場合は、初回起動の前に `docker-compose.yml` の environment に `- SEED=0` を追加
- すでに使っている辞書に入れたいときは、アプリの「CSVからインポート」→「基本情報の用語まとめ（304語）」→ 重複は「スキップ」でインポート

## API（参考）

`:d` は辞書のID。

| メソッド | パス | 内容 |
|---|---|---|
| GET / POST | `/api/dictionaries` | 辞書一覧（単語数・タグ数つき）/ 作成 `{name}` |
| PUT / DELETE | `/api/dictionaries/:d` | 名前変更 / 削除（中の単語・タグも削除。最後の1つは削除不可） |
| GET / POST | `/api/dictionaries/:d/words` | その辞書の全単語（`tagIds` 付き）/ 追加 `{word, reading, meaning, tagIds}` |
| GET / POST | `/api/dictionaries/:d/tags` | その辞書のタグ一覧 / 追加 `{name, color}` |
| POST | `/api/dictionaries/:d/import` | `{rows:[{word,reading,meaning,tags:[名前]}], mode:"skip"|"overwrite"|"append"}` |
| GET | `/api/dictionaries/:d/export` | CSV ダウンロード（UTF-8 BOM付き） |
| PUT / DELETE | `/api/words/:id` | 単語の更新 / 削除 |
| PUT / DELETE | `/api/tags/:id` | タグの更新 / 削除 |
| GET | `/api/health` | 死活確認 |

### 前のバージョン（v1）から更新したとき

起動時に自動でデータを移行します。今までの単語とタグはすべて「基本情報辞書」に入り、どの単語にも使われていない色名だけのタグ（レッド・オレンジ…）は削除されます。念のため、更新前に `data` フォルダをコピーしておくと安心です。
