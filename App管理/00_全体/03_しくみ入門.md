# しくみ入門（はじめての人向け）

「なぜそう動くのか」を、前提知識なしで読めるように書いたものです。Docker のしくみは `Docker/01_しくみ.md`、Tailscale のしくみは `Tailscale/01_しくみ.md` にあります。

## 17-1. まず3つの言葉

| 言葉 | 意味 | この倉庫では |
| --- | --- | --- |
| サーバー | 他の端末からの「これをください」に応えて返すプログラム、またはそれが動く機械 | Mac mini。その中で nginx などが応えている |
| IP アドレス | ネットワーク上の機械の住所 | Tailscale 用の住所が `100.x.y.z` |
| ポート | 1台の機械の中の「窓口の番号」。1つの住所に窓口がたくさんある | 3000 番がポータル、8081 番が nginx、22 番が SSH |

`http://100.x.y.z:8081/my-dictionary/` は「住所 100.x.y.z の、8081 番窓口に、/my-dictionary/ をください」という意味です。

## 17-4. nginx と HTTPS

| 言葉 | 意味 |
| --- | --- |
| Web サーバー | ブラウザの求めに応じて HTML などのファイルを返すプログラム。nginx がこれ |
| リバースプロキシ | 入口で受けて、URL を見て裏の別のプログラムに取り次ぐ役。nginx が `/api/` を KVストアへ、`/my-dictionary/` を辞書へ取り次いでいる |
| HTTP / HTTPS | HTTPS は暗号化と「相手が本物か」の証明が付いた HTTP |
| オリジン | 「http か https か＋住所＋ポート」の組。これが同じなら、ブラウザは画面と API のやり取りを自由にさせる |

倉庫は HTTP（`http://100.x.y.z:…`）で動いています。通路そのものが Tailscale で暗号化されているので盗み見はされません。ただしブラウザは「HTTP のページ」と見なすため、位置情報の取得と、オフラインで開く機能（Service Worker）は使えません。これらが必要なアプリ（coupon-checker）は、Tailscale Serve で HTTPS にします。

## 17-5. ターミナル・シェル・SSH

| 言葉 | 意味 |
| --- | --- |
| ターミナル | 文字で命令を打つための窓。サーバーの機能ではなく、全部を操作する道具 |
| シェル | 打った命令を解釈して実行するプログラム。Mac の標準は zsh。スクリプトは bash で書いている |
| プロンプト | `youruser@Your-Mac ~ %` のような入力待ちの表示。「ユーザー名@機械の名前 今いる場所 %」。`%` が出ていれば次の命令を打てる |
| SSH | 別の機械のターミナルを、暗号化した通信で遠隔操作する仕組み。`ssh skymac` で Mac mini に入る |
| sudo | 管理者の権限で実行する（super user do）。パスワードを聞かれる |
| パイプ `\|` | 左の命令の結果を、右の命令に渡す |
| リダイレクト `>` | 結果を画面ではなくファイルに書く。`>/dev/null` は「捨てる」 |

## 17-7. タイルを押してから画面が出るまで

iPhone の「倉庫」で「My辞書」を押したときに起きることです。

1. iPhone の Safari が `http://100.x.y.z:8081/my-dictionary/` を開こうとする
2. `100.` で始まる住所なので、iPhone の Tailscale が通信を引き受け、暗号化して Mac mini へ送る（Tailscale がオフだと、ここで行き先が無く、開けない）
3. Tailscale の ACL が「自分の端末から tag:server の 8081 番」を許可しているので通る
4. Mac mini の 8081 番で Docker が受け取り、`apps-static`（nginx）の 8080 番へ渡す
5. nginx が URL の頭 `/my-dictionary/` を見て、`dictionary` コンテナの 8080 番へ取り次ぐ
6. 辞書のプログラムが、画面のファイル（HTML・CSS・JavaScript）を返す
7. 画面の JavaScript が `api/dictionaries` などを呼び、辞書のプログラムが `~/server/data/dictionary/dictionary.db` から単語を読んで返す
8. 同じ道を逆にたどって iPhone に届き、画面に出る
