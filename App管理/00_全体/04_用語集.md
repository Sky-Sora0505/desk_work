# 用語集

この資料に出てくる言葉の意味です。

## 16-1. 用語集

| 用語 | 意味 |
| --- | --- |
| 倉庫 | このサーバーの通称。ポータルのタイトル「倉庫サーバー」、iPhone のアイコン名「倉庫」 |
| tailnet | 自分の Tailscale ネットワーク。この環境は `your-tailnet` |
| MagicDNS | tailnet 内で端末を名前で引ける仕組み |
| ACL ・ grants | 誰がどの端末のどのポートに届くかのルール。grants は新しい書き方 |
| バインド | どの IP アドレスで待ち受けるか。`100.x.y.z:8081` なら Tailscale 経由だけ、`*:8081` なら全部 |
| bind mount | Mac のフォルダをコンテナの中に見せる方法。データは Mac 側に残る |
| リバースプロキシ | 入口でリクエストを受け、内側のサーバーに中継するもの。ここでは nginx |
| KVストア | Key-Value（キーと値）を保存するだけの保存サーバー |
| 楽観的ロック | 「読んだときの版」を付けて書き込み、その間に他の人が書いていたら拒否する方式。古い画面からの上書きを防ぐ |
| リビジョン | 保存のたびに1ずつ増える版番号 |
| healthcheck | Docker が定期的にアプリの生存を確かめる仕組み。`(healthy)` と表示される |
| CP（チェックポイント） | 各 Phase の合格条件。「つながる」と「つながらない」の両方を確かめる |
| 負のテスト | 「できてはいけないことができない」の確認（Tailscale オフで開かない、など） |
| 単一障害点 | そこが破られると全体が破られる1か所。この構成では GitHub アカウント |
| RPO / RTO | どこまで戻せるか / 復旧にかかる時間 |
| CLAUDE.md | Claude Code が起動時に読む、そのリポジトリの前提と約束 |
