# macOS のコマンド

電源・セキュリティ・状態確認のコマンドです。

## 15-3. macOS（電源・セキュリティ・状態）

| コマンド | 意味 | 語源・補足 |
| --- | --- | --- |
| `pmset -g` | 電源設定の一覧 | power management settings、`-g` = get |
| `sudo pmset -a sleep 0 disksleep 0 autorestart 1` | スリープ禁止・停電後自動起動 | `-a` = all（電源の種類すべて） |
| `pmset displaysleepnow` | 画面だけ消す | スリープではないので外からつながる |
| `pmset -g therm` | 温度・熱による制限の状態 | therm = thermal |
| `fdesetup status` | FileVault の状態 | full disk encryption setup |
| `sudo fdesetup authrestart` | 認証を引き継いで再起動 | リモート再起動はこれ |
| `sudo shutdown -h now` / `-r now` | 電源オフ / 再起動 | h = halt、r = reboot |
| `sudo /usr/libexec/ApplicationFirewall/socketfilterfw --getglobalstate` | ファイアウォールの状態 | `--setglobalstate on`、`--setstealthmode on` で設定 |
| `sudo lsof -iTCP -sTCP:LISTEN -n -P` | 待ち受け中の TCP ポートとプロセス | list open files。`-n -P` は名前を引かず数字で表示（速い） |
| `sudo sshd -T` | sshd の実際に有効な設定 | T = test（拡張モード） |
| `sw_vers` | macOS のバージョン | software versions |
| `id -u` / `id -g` | ユーザー ID / グループ ID（501 / 20） | compose の `user` や PUID/PGID に使う |
| `diskutil list external` | 外付けドライブの一覧 | ドライブ購入後に使う |
| `tmutil destinationinfo` | Time Machine の保存先 | 何も出なければ未設定 |
