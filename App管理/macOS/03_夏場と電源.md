# 夏場の運用・電源・やってはいけないこと

暑い時期の止め方と、禁止事項です。

## 5-7. 夏場の運用と、外出時の止め方

Mac mini が動いてよい室温は 10〜35℃ です（電源オフなら -40〜47℃）。エアコンなしで締め切った夏の部屋は 38〜42℃ になり得るので、その場合は外出前に電源を切ります。Mac mini 自体はアイドル時に数W しか使わず、部屋を暖めることはありません。問題は「暑い部屋で動かし続けること」です。

| 室温（実測） | 対応 |
| --- | --- |
| 32℃ 未満 | 通常運用でよい |
| 32〜35℃ | 外出時はスリープ。置き場所を見直す |
| 35℃ 超 | 外出時はシャットダウン |

まず室温を1週間測ります（SwitchBot などの温湿度計なら外出先からも見られる）。Mac 側の熱の状態は `pmset -g therm` で見ます。当初案の `sudo powermetrics --samplers smc` は Apple Silicon では温度が取れないため、使いません。

| 止め方 | 評価 | 補足 |
| --- | --- | --- |
| A. 手動でシャットダウン → 帰宅後に電源ボタンとログイン | おすすめ | いちばん単純で安全。`down.sh && sudo shutdown -h now` |
| B. `pmset` で毎日の自動オン・オフ | 条件付き | 起動は自動でも、FileVault のためログインは手動。ログインするまで何も動かない |
| C. スリープ | 熱対策としては十分 | 消費電力は 1W 未満で発熱はほぼ電源オフと同じ。**スリープ中は外からつながらない**。今は `sleep 0`（スリープしない設定）なので、使うなら Apple メニューから手動で |
| D. スマートプラグで給電を切る | **禁止** | コンセントを抜くのと同じ。DB が壊れる |

B のコマンドは次のとおりです。複数の予定は必ず1つのコマンドにまとめます（別々に2回打つと、後のものが前のものを消す）。スリープ中やログアウト中は、予定どおりにシャットダウンされません。

```bash
sudo pmset repeat shutdown MTWRFSU 08:00:00 wakeorpoweron MTWRFSU 19:00:00
pmset -g sched
sudo pmset repeat cancel
```

| 置き方の注意 | 理由 |
| --- | --- |
| 底面を塞がない。布・カーペット・座布団の上に直接置かない | Mac mini M4 は底面から吸気し、背面に排気する |
| 密閉された棚やラックに入れない | 自分の排気を吸い直して熱がこもる |
| 直射日光の当たる場所（窓際）を避ける | 本体が直接温まる |
| 在宅時はサーキュレーターを回す | 数℃ 変わる |
| 電源ボタンに手が入るよう少し浮かせて置く | ボタンが底面にある |

ローカル LLM を動かすと GPU が全開になり、数十W の熱が出ます。LLM は在宅時だけにします（13-4）。

## 5-8. やってはいけないこと

| 禁止事項 | 理由 |
| --- | --- |
| 電源ケーブルを抜く、スマートプラグで給電を止める | データベースが壊れる |
| バックアップ用の Drive B を常時つないだままにする | ランサムウェアに一緒に暗号化される |
| ルーターでポートを開放する | 攻撃対象になる。Tailscale があれば不要 |
| Tailscale の外で SMB（445番）を使う | ランサムウェアの主な感染経路 |
| `tailscale funnel` を使う、つけっぱなしにする | インターネットに公開された状態が続く |
| DB のパスワードを使い回す | 片方が漏れると両方やられる |
| バックアップから戻すテストをしない | 壊れたバックアップに気づけない |
| OS のアップデートを放置する | ポートを閉じていても、長期的には最大のリスク |
