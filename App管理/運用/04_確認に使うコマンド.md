# 確認・試験に使うコマンド

curl や grep など、確かめるときの道具です。

## 15-4. 確認・試験に使う道具

| コマンド | 意味 |
| --- | --- |
| `curl -s <URL>; echo` | ページや API の中身を取る。`-s` = silent、`echo` は改行を足すため |
| `curl -s -o /dev/null -w "%{http_code}\n" <URL>` | 中身を捨てて HTTP ステータスだけ表示（200 / 404 / 502） |
| `curl -s -X PUT -H "X-Expected-Revision: 0" --data '値' <URL>` | メソッド（`-X`）、ヘッダ（`-H`）、本文（`--data`）を指定 |
| `curl -i <URL>` | 応答ヘッダも表示（ETag の確認など） |
| `grep -n "文字" <ファイル>` | 行番号付きで検索。g/re/p（global / regular expression / print）が語源 |
| `find ~ -maxdepth 3 -type d -name <名前>` | フォルダの場所を探す |
| `ls -lt <場所> \| head` | 新しい順に先頭だけ |
| `diff -r <A> <B>` | 2つのフォルダの差分 |
| `nano <ファイル>` | 簡単な編集。保存 `Ctrl+O` → Enter、終了 `Ctrl+X` |
| `cat > <ファイル> << 'EOF'` 〜 `EOF` | 複数行をファイルに書く（ヒアドキュメント）。`'EOF'` と引用符を付けると `$` が展開されない |
| `cmd1 && cmd2` / `cmd1 \|\| cmd2` | 成功したら次 / 失敗したら次 |
| `chmod +x` / `chmod 600` | 実行権限を付ける / 持ち主だけ読み書き（change mode） |
