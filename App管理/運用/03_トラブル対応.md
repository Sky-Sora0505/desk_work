# トラブル対応・ハマりどころ集

症状から引ける早見表と、macOS・ターミナルの落とし穴です。

iPhone から開かないときは、まず iPhone 側の Tailscale がオンかを見ます。これまでの「開かない」は、ほとんどが iPhone 側の切断か Mac のスリープでした。

## 12-1. 症状別の早見表

| 症状 | まずやること |
| --- | --- |
| iPhone から開かない・Not Connected | iPhone の Tailscale をオンにする。Mac で `tailscale status` を見て iPhone が `offline` なら iPhone 側の問題 |
| それでも開かない | Mac mini がスリープしていないか。スリープ中は外から届かない |
| 電源を入れたのにつながらない | ログインしたか（FileVault の仕様で、ログイン前は何も動かない） |
| `status.sh` で Docker が未起動 | `~/server/scripts/up.sh`（Docker も起動する）。手動なら `open -a Docker` |
| `docker.sock: no such file or directory` | Docker Desktop が動いていない。上と同じ |
| up.sh が「Tailscale が接続されていません」 | メニューバーの Tailscale アイコンで接続。`bash -c 'tailscale ip -4'` で IP が出るか |
| ポートが `*:3000` のように出る | compose の `ports` に IP が欠けている。すぐ止めて直す |
| ポータルが表示されない | `docker logs homepage --tail 20`。`Host validation failed` なら `HOMEPAGE_ALLOWED_HOSTS` に足す |
| タイルが出ない・アイコンが空白 | YAML のインデント、アイコン名の打ち間違い（例 `mdi-language-jave`） |
| `/api/health` が 502 | KVストアが止まっている。`docker compose logs --tail=20 kvstore` |
| `/my-dictionary/` が 502 | 辞書が止まっている。`docker compose logs --tail=20 dictionary` |
| nginx が起動しない | `default.conf` の書式ミス。`docker compose logs apps`、`.bak` から戻す |
| コンテナが `(unhealthy)` | `docker inspect --format '{{json .State.Health}}' <コンテナ名>` でヘルスチェックの結果を見る |
| KVストアが起動しない | ログに原因と対処が日本語で出る（例 `KV-500-11` データフォルダに書けない → compose の `user` とフォルダの持ち主を確認） |
| 進捗が共有されない | 開き直したか。`curl -s "…/api/kv?prefix=jsilver17"` で保存されているか |

## 12-2. macOS 特有の落とし穴

| 現象 | 原因 | 解決 |
| --- | --- | --- |
| `tailscale` が `bundleIdentifier is unknown` で落ちる | シンボリックリンク経由だとアプリが自分の場所を特定できない | ラッパースクリプト（5-4）かフルパス |
| `tailscale up` で `requires mentioning all non-default flags` | `up` は設定の上書き。書かないオプションは初期値に戻る | エラー文に正しいコマンドが出るのでそれを使う（今回は `--accept-routes` を足した） |
| Tailscale SSH が使えない | macOS のアプリ版はサーバー側非対応 | OpenSSH の鍵認証 |
| `ListenAddress` が効かない | launchd のソケット起動 | 使わない。鍵認証＋`AllowUsers` |
| sshd_config の末尾に書いても効かない | `Include` が先に読まれ「最初の値が勝つ」 | `sshd_config.d/99-hardening.conf`、`sudo sshd -T` で確認 |
| `powermetrics` で温度が取れない | Apple Silicon は非対応 | `pmset -g therm` |
| `sudo cat > ファイル` が権限エラー | `>` は sudo が効く前にシェルが処理する | `sudo tee ファイル > /dev/null` |
| `sed -i` がエラー | macOS の sed は `-i` の後に拡張子が必要 | `sed -i '' '…'` |
| `python3 -c "import yaml"` が失敗 | Mac の python3 に PyYAML がない | 入れずに、コンテナのログや `docker compose config` で確認 |
| `df -h` の使用量と空きが合わない | APFS のスナップショットやパージ可能領域 | 実害は薄い。`df -H /System/Volumes/Data` |

## 12-3. ターミナル操作の落とし穴

| 現象 | 原因 | 対処 |
| --- | --- | --- |
| `zsh: command not found: #` | zsh の対話モードは `#` をコメントとして扱わない | 害はない。コピペ用のブロックにはコメント行を入れない |
| `^[[200~` が混じる | 複数行を貼ったときのブラケットペースト | 基本は1行ずつ貼り、`%` が戻ってから次へ。`cat << 'EOF'` 〜 `EOF` だけはまとめて貼る |
| `zsh: parse error` | `<My_BOXのclone先>` のような置き換え用の文字をそのまま貼った（`<` `>` はリダイレクト記号） | `find ~ -maxdepth 3 -type d -name My_BOX` などで実際のパスを調べて入れる |
| `sleep 30` の間に次を貼って結果が欠ける | 前のコマンドが終わる前に出力をコピーした | プロンプト `%` が戻るまで待つ |
| フォルダ名に空白（例 `files _sarver`、`Java Silver`） | 空白で引数が切れる | `"$HOME/コーディング/files _sarver/…"` のように `"` で囲む |
| psql の中でシェルのコマンドを打った | プロンプトの違い（`%` シェル / `training=#` psql / `training-#` 文の途中） | psql は `\q` で抜ける（`Ctrl+C` ではない） |
| ダウンロードしたはずのファイルが無い | iPhone や別の PC で保存した、または名前が `index (1).html` になった | Mac mini のブラウザで保存し、`ls -lt ~/Downloads` で新しい順に見る |
| `tailscale serve` を止め忘れた | 単体版を片付けた後も HTTPS 公開が残る | `tailscale serve --https=443 off` → `tailscale serve status` で `No serve config` |
